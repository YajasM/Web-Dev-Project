# My Portfolio

## About

Personal portfolio for Yajas Malhotra, a CS student at BITS Pilani
(B.Sc. Computer Science) and Scaler School of Technology (UGP, AI &
Business), competitive programmer, and aspiring quant developer.
Built while learning HTML, CSS and Tailwind CSS from scratch.

Link : https://yajasm.github.io/Web-Dev-Project/

## Technologies

- HTML
- CSS
- Tailwind CSS (via CDN, used for layout utilities like flex/grid/gap/padding)
- Vanta.js + Three.js (animated moving line background)

## Features

- Sticky navigation bar linking to every section
- Hero section with profile photo and CTA buttons
- About, Skills, Projects and Contact sections
- Fully responsive layout (stacks nicely on mobile)
- Layout built with Flexbox and CSS Grid
- Box model used throughout for spacing, borders and cards
- CSS transitions on buttons, links and project cards
- CSS keyframe animation on the moving background
- Working internal nav links + external links (GitHub, LinkedIn, email)
